# Artwork and accessibility

Only original project artwork is included. The supplied anime avatar and manga
banner were excluded because redistribution rights were not verified.

- `ocean-banner.svg`: original abstract ocean waves in midnight navy, ocean blue
  and ice blue. The SVG source is MIT licensed.
- `mascot-sheet.png`: original chibi design generated with OpenAI imagegen for this
  project from the descriptive prompt below; no supplied anime frames were used.
- `mascot.gif` and `mascot-static.png`: 72px derivatives of that sprite sheet.
  The transparent GIF blinks and waves over three seconds. A static profile is
  linked because GIFs do not universally honor reduced-motion preferences.
- `typing.svg`: original animated SVG source under MIT, with reduced-motion CSS,
  a static SVG alternative and plain-text alt wording.

The MIT source-code grant excludes raster artwork. See [asset licensing](../assets/NOTICE.txt)
for provenance and the separate raster-asset terms. The original static mascot is
available as an avatar alternative; publishing this README does not change account settings.

Generation prompt: original pixel-art chibi developer; brown tousled hair, black
rectangular glasses, small red bow, navy outfit, ice-blue accents; transparent background;
four aligned full-body frames: neutral, blink, hand raised, wave. No copied character,
text, logos, props or watermarks. Generated through the built-in imagegen tool.

The proposed wbthekid.my.id address served a parked-domain page at review time and
is not linked as a portfolio until real content is deployed and verified.
