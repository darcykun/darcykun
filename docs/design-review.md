# Profile redesign notes

## Direction

A monochrome editorial opening, an original geometric wordmark, native GitHub body
text and restrained ocean-blue accents. Full-Stack Developer is the owner's chosen
identity; the copy does not imply employment, seniority or production experience.
The hero establishes identity, the project establishes evidence, and the remaining
sections separate demonstrated work from learning. No decorative badges or metrics.

The front page is single-column with ordinary headings, prose, lists and links.
It does not depend on custom layout CSS. The preview stylesheet is a local review
aid, not part of the profile payload.

## Project evidence reviewed

- [agent-workbench](https://github.com/darcykun/agent-workbench), commit
  `0c76f90dd7e0a572dac4b849142fce9db799b801`: Python runtime, Pydantic schemas,
  Typer CLI, SQLite metadata storage, scoped tools, approvals and tests.
  [CI](https://github.com/darcykun/agent-workbench/actions/runs/40473842357) passed
  on Python 3.12 and 3.14. This supports the precise technologies listed in the
  profile, not mastery or production deployment. It remains a source candidate;
  the live Ollama model has not been validated and no package is released.
- `baileys`: existing TypeScript implementation and dependency manifest inspected.
  GitHub reports no license, and original authorship/provenance was not established.
  It is not featured; dependency names are not treated as verified proficiency.
- `aqeeldb`, `verify.json` and legacy identity READMEs do not supply a demonstrated
  full-stack application suitable for the featured slot. No claims are copied from them.
- Original SVG/code work in this profile is not evidence of a shipped frontend
  application. Frontend languages are labeled Learning.

## Inspiration, not templates

Reviewed [Anthony Fu](https://github.com/antfu),
[Sindre Sorhus](https://github.com/sindresorhus), and [Lee Robinson](https://github.com/leerob).
Useful principles: compact navigation, concise personal writing and emphasis on
actual repositories. No wording, artwork, distinctive assets or layout was copied.
The illustrated banner and custom lettering were created specifically for Dar KUN!.

## Motion and activity

The title and banner are static. The existing mascot is the only animated accent;
there is a reduced-motion source and a separately linked static profile. Earlier
typing animations remain available but are not embedded in the redesigned README.
Activity links to GitHub's native Overview and actual commits. No stats service,
synthetic graph or unverified snake output is displayed. Existing workflow
configuration is unchanged and has not been dispatched.

## Review boundary

Local redesign candidate. No commit or push is authorized by this design request.
No existing asset is deleted. Only this profile working copy is edited;
agent-workbench and legacy repository source remain untouched.
