# Current direction

The profile presents a full-stack direction; demonstrated technologies are tied to
published work, not inferred from interests or a list of dependencies.

## Published foundation

[agent-workbench](https://github.com/darcykun/agent-workbench) implements a bounded
Python runtime, approval checks, confined document reads and SQLite event metadata.
The offline demo and CI run; live-model behavior and a package release remain future work.

## Exploring

- Accessible frontend interfaces and how they connect to APIs.
- Backend integrations, application data models and full-stack architecture.
- Developer tooling and automation with explicit failure handling.
- AI agent systems and reproducible LLM evaluation.

The runtime's [capability roadmap](https://github.com/darcykun/agent-workbench/blob/main/docs/roadmap.md)
tracks its next engineering steps. New projects will be linked when working code and
validation exist. This profile does not claim completed frontend applications or deployments.
