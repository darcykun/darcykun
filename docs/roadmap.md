# Engineering roadmap

1. Review and publish the tested `agent-workbench` v0.1 candidate. Validate GitHub CI
   and installation before linking it as selected work or pinning it.
2. Add durable operation outcomes and test against one installed local model.
3. Build `mcp-toolbox` around a real protocol client integration and scoped tools.
4. Build `rag-eval-lab` with an original corpus and hand-checked retrieval metrics;
   then extract reusable evaluation contracts into `llm-eval-kit`.
5. Consider `research-pipeline` and `local-model-gateway` only after maintaining the
   earlier projects is sustainable.

Progress is measured by working capabilities and failure tests, not commit counts.
