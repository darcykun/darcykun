### `> featured_project`

**[agent-workbench](https://github.com/darcykun/agent-workbench)**

A Python runtime for experimenting with bounded AI-agent tool execution.

Features include:

- **Explicit tool approvals** — permission checks before actions execute.
- **Scoped document access** — restrict which files tools can read.
- **Execution budgets** — limit agent resource usage.
- **Cancellation handling** — stop operations predictably.
- **Replayable traces** — inspect runtime event metadata.
- **Automated tests** — validate expected behavior and failure paths.

**[Explore the source code →](https://github.com/darcykun/agent-workbench)**
