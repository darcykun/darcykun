## About

I’m Dar KUN!, a full-stack developer interested in the details between an interface,
an API, and a database. My current public work focuses on Python developer tools and
practical AI agent systems. I like small, understandable systems with clear boundaries.

## Featured work

### [agent-workbench](https://github.com/darcykun/agent-workbench)

A bounded tool-calling runtime with explicit approvals, confined document reads,
and replayable event metadata. Includes an offline CLI demo and failure-path tests.

<sub>Python · Pydantic · Typer · SQLite · pytest</sub>

[Source](https://github.com/darcykun/agent-workbench) · [Architecture](https://github.com/darcykun/agent-workbench/blob/main/docs/architecture.md) · [CI](https://github.com/darcykun/agent-workbench/actions/workflows/ci.yml)
